# vyshyvankadaily-blog

Скіл для блогу [VyshyvankaDaily](https://vyshyvankadaily.live) - двомовного сайту про регіональну вишивку й українську культуру.

## Що вміє

1. Пропонує теми й оцінює їх за 7 критеріями (попит, шанс у видачі, перевага, перелінковка, сезон, шеринг, ризик).
2. Збирає ключі й бриф за видачею конкурентів.
3. Пише статтю українською, потім англійською, за правилами тону й SEO сайту.
4. Чистить текст від шаблонних AI-зворотів, перевіряє факти й E-E-A-T.
5. Проганяє аудитор і створює один HTML-файл для рев'ю: мета-дані, бриф, таблиця перевірок і повний текст UA та EN з фото.

## Аудитор

```bash
python3 scripts/audit_article.py draft.json --repo <repo> --out review.html
```

Лише стандартна бібліотека Python 3.8+. Перевіряє обсяг, мета-поля, ключ у title, H2, перших 100 словах і абзацах, FAQ, фінальний рядок, внутрішні й зовнішні посилання, зображення, тире й лапки, шаблонні звороти, ритм речень. Код виходу 1, якщо є помилки.

## Файли

- `SKILL.md` - процес з 11 кроків
- `references/style.md` - тон, заборонені шаблони, типографіка
- `references/seo.md` - on-page правила, перелінковка, 27 регіонів
- `references/topics.md` - шкала оцінки й банк тем
- `references/publishing.md` - формат чернетки, зображення, публікація
- `scripts/audit_article.py` - аудитор і HTML-звіт
